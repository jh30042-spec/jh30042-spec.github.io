# 💨 엘리베이터 눈치 방귀 참기

엘리베이터에 탄 사람들 사이에서 방귀를 참아내는 모바일 웹 미니게임입니다.
한 개의 HTML 파일(`index.html`)로 동작하며, 설치 없이 링크만 열면 바로 플레이할 수 있습니다.

## 플레이 방법

- 화면을 **누르고 있으면** 방귀를 참습니다. 손을 떼면 터집니다.
- 게이지가 한계에 가까울수록 참기 어려워지니, 타이밍을 봐서 **문이 열린 순간**에 내보내세요.
- 옆 사람의 눈치(시선) 게이지가 가득 차면 들킵니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 게임 전체 (HTML + CSS + JavaScript, 외부 의존성 없음) |
| `.nojekyll` | GitHub Pages에서 Jekyll 처리 없이 정적 파일 그대로 서빙 |

## 실행

`index.html`을 브라우저로 열면 됩니다. 서버가 필요 없습니다.

## 배포

GitHub Pages로 서빙 중입니다. `main` 브랜치 루트가 배포 소스입니다.
